# winners-pot-buttons

BepInEx 5 plugin for Black Jacket. Adds `+` / `-` buttons to the winners pot during a match.

`+` spawns coins into the pot, `-` removes them (regular coins first). The pot size cap is respected by
default; settings live in `BepInEx/config/com.blackjacket.mods.winnerspotbuttons.cfg` after the first launch.
